# 생활루틴

40대 남성의 몸과 집을 하나의 화면에서 관리하는 웹앱.

- **신체 지도** — 11개 부위별 관리법을 근거 등급(A/B/C)과 함께 제공
- **집 평면도** — 전용 84.99㎡ 도면 위를 걸어다니며 각 공간의 활동을 타이머로 실행
- **보관함** — 냉장고·옷장·영양제 등을 노션식 표로 관리
- **체형 반영** — 키·몸무게에 따라 인물이 변형되고 목표 체형이 윤곽선으로 겹쳐짐
- **기기 간 동기화** — GitHub Gist에 암호화(AES-GCM)해서 저장

## 구조

`index.html` 파일 하나로 동작한다. 빌드 과정이 없다.
내부는 네 층으로 나뉘어 있다.

1. 데이터 — 건강 정보, 평면도 기하, 기본 활동/물품
2. 저장소 — localStorage, 동기화
3. 타이머·알림, 체형 변형 엔진
4. 렌더링

## 개인정보

- 기록은 기본적으로 브라우저에만 저장된다.
- 동기화를 켜면 **기기에서 암호화한 뒤** Gist에 올라간다. 암호는 전송되지 않는다.
- 이 페이지 자체에는 어떤 개인 데이터도 들어있지 않다.

## 면책

일반적인 건강 정보이며 의학적 진단·치료를 대신하지 않는다.
